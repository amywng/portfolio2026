# Amy's Portfolio

Personal portfolio site built with Next.js, TypeScript, Tailwind CSS, Supabase, and Spotify's API.

## Tech Stack

- **Next.js 15** — App Router
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** — animations
- **Supabase** — database / content
- **Spotify Web API** — recently played music
- **next-themes** — dark / light mode
- **react-simple-maps + d3-geo** — map visualizations
- **Vercel** — deployment

---

## Getting Started

### Requirements

- Node.js 18.18+ or newer
- npm
- A Supabase project if using database-backed content
- A Spotify Developer application if using the Spotify integration

### Install dependencies

```bash
npm install
```

## Project Structure

```text
app/          # Pages, layouts, and API routes
components/   # Reusable UI components
data/         # Static content and configuration
hooks/        # Custom React hooks
lib/          # Supabase, Spotify, and shared utilities
public/       # Images, moodboard assets, and other static files
scripts/      # Local utility scripts
```
